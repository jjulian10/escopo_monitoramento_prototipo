# SCOPE

### Sistema de Controle de Planos Estratégicos

Protótipo de sistema web desenvolvido para explorar uma solução de acompanhamento de planos, projetos estratégicos, indicadores, responsáveis e evolução das entregas.

> **Projeto demonstrativo:** todos os dados apresentados neste projeto são fictícios e utilizados exclusivamente para fins de demonstração.

## Sobre o projeto

O SCOPE foi desenvolvido como uma proposta de interface para centralizar informações relacionadas ao planejamento e acompanhamento de projetos estratégicos.

A ideia é facilitar a visualização da situação dos projetos e transformar informações de acompanhamento em uma experiência mais simples e organizada.

O projeto explora conceitos relacionados a:

- gestão de projetos;
- planejamento estratégico;
- indicadores;
- acompanhamento de entregas;
- organização de informações;
- dashboards;
- experiência do usuário.

---

## Funcionalidades

O protótipo apresenta conceitos como:

- dashboard de acompanhamento;
- visualização de projetos estratégicos;
- indicadores de progresso;
- acompanhamento de etapas;
- organização por status;
